# Titanic Dataset – Data Understanding & ML Readiness

## Objective
To understand the structure, data types, and machine learning suitability of the Titanic dataset.

## Tasks Performed
- Loaded the dataset using Pandas
- Inspected first and last few records
- Identified numerical, categorical, ordinal, and binary features
- Used df.info() and df.describe() for data inspection
- Checked unique values in categorical columns
- Identified target and input features
- Analyzed dataset size
- Observed data quality issues such as missing values

## Files Included
- `T-1.ipynb` – Jupyter Notebook with all code and outputs
- `test.csv` – Dataset used for analysis

## Outcome
The dataset structure and data quality were analyzed to determine readiness for machine learning.
